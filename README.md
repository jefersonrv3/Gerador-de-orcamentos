<h1>
  Projeto Gerador de orçamentos simples
</h1>

<h2>Meu pai tinha dificuldades para criar orçamentos em sua oficina devido a falta de equipamento e tempo para mexer com excel e planilhas complexas. Então resolvi criar eu mesmo uma aplicação simples para criar nota de serviços e orçamentos para imprimir e mandar para o cliente via pdf.</h2>

<p> sempre tivemos o desafio de fazer à mão cada um dos orçamentos dos clientes e para controlar isso dentro da oficina. Agora pretendo com essa aplicação facilitar pelo menos um pouco o trabalho de criação de orçamentos.</p>
